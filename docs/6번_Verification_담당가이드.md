# 6번 화면·검증 담당 가이드

6번은 실제 API를 사용하는 Streamlit 화면, runner 어댑터, 브라우저별 세션과 검증 도구를 담당한다. 기관 조회와 전체 에이전트 상담의 연결 상태를 구분하고, 실행하지 않은 기능을 통과로 기록하지 않는다.

## 화면 운영 흐름

1. **의료기관 조회:** 좌표와 반경을 입력하고 조회한다. 실제 API에서 받은 기관명·거리·대표전화 등을 확인한 뒤 기관을 선택해 상세 정보를 조회한다. 화면 재실행만으로 다시 조회하지 않는다.
2. **에이전트 상담:** 연결 확인 후 위치와 증상을 입력한다. 응답 후보를 선택하고 방문 계획의 승인·거절을 처리한다. 연결 실패 시 오류 상태를 안내한다.
3. **연결 상태:** 세 API 키의 설정 여부와 runner 연결 결과를 확인한다. 키 값은 표시하지 않는다. 키 설정과 인증 성공은 별개다.

프로젝트 루트에서 실행한다.

```bash
uv sync --frozen --extra dev
uv run --frozen streamlit run streamlit_app.py
```

기존 `.env`에 `OPENAI_API_KEY`, `KAKAO_REST_API_KEY`, `EGEN_SERVICE_KEY`를 설정한다. 전체 상담이 막혀 있어도 의료기관 직접 조회 경로는 별도로 확인할 수 있다. 기관 목록을 진료 수용 확정이나 예약 결과로 설명하지 않는다.

## 코드 책임

| 경로 | 담당 내용 |
|---|---|
| `web/app.py`, `web/components.py` | 세 탭, 결과 표시, 입력·승인·삭제 이벤트 |
| `web/api_view.py` | 명시적 의료 API 조회와 마지막 조회 결과 보관 |
| `web/live.py` | 실제 provider·모델·runner 조립, 연결 상태, 화면 응답 변환 |
| `web/state.py`, `web/contracts.py` | 브라우저별 대화와 표시용 계약 |
| `scripts/verify.py` | 오프라인 테스트 실행과 JSON/JUnit/로그 기록 |
| `tests/integration/`, `tests/unit/web/` | 화면 이벤트·저장 효과·호출 횟수·오류 경계 검증 |

모델·검색·메모리·가드레일 자체의 오류는 담당 모듈에서 고친다. 현재 `main`의 `33e9f22`에는 공통 모델 구문과 memory import/상태 계약 오류가 남아 있다. 상담 어댑터는 이 실패를 표시하며 원본 모듈을 임시 별칭이나 다른 결과로 바꾸지 않는다.

## 반드시 확인할 사용자 흐름

- 브라우저별 대화·주소·저장 기록이 섞이지 않는가.
- 기본 주소 저장 동의와 철회가 반영되는가.
- 승인 전·거절 후 저장은 0회이며 승인 후 1회인가.
- 이동수단 변경이나 새 대화와 승인 이벤트가 겹쳐도 이전 계획이 저장되지 않는가.
- 재실행만으로 API 조회나 저장이 반복되지 않는가.
- 전체 삭제 후 상담 기록·프로필·의료기관 조회 결과가 남지 않는가.
- API 오류·빈 응답·누락 필드가 구분되고 원문 예외나 키 값이 화면에 노출되지 않는가.

## 결과 기록

```bash
uv run --frozen python scripts/verify.py
```

`verification-results/report.json`, `junit.xml`, `pytest.log`를 확인하고 [검증 기록](verification.md)을 갱신한다. 테스트 수집 오류가 있으면 실행 가능한 테스트가 통과해도 전체 FAIL이다. 정적 사전 검사만으로 통합 PASS를 선언하지 않는다.

오프라인 테스트의 fixture·주입 runner는 화면 계약을 검증하기 위한 것이다. 실제 API 조회, 실제 LLM 응답, LangGraph 승인 재개와는 증거를 분리한다. API 호출 성공 횟수·결과와 시험 시각은 실제 실행 후 기록하며, pytest 실행 시간을 추천 지연 시간으로 사용하지 않는다.

모듈 간 인수 조건은 [UI 연결 계약](ui-integration.md), 이전 커밋의 발견 사항은 [e97341a 검토 기록](review-2026-09-11.md)을 참고한다.
